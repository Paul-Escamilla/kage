# El Proyecto Kage 🕸️

Bienvenido a la documentación oficial de **Kage**. 

En este repositorio se desarrolla un algoritmo altamente eficiente para la creación y búsqueda de **jaulas** (cages) en la teoría de grafos. Nuestro enfoque se apoya fuertemente en la técnica de **backtracking** para optimizar el proceso de búsqueda.

## ¿De qué trata este proyecto?
El objetivo principal de esta documentación es explicar a detalle cómo funciona la lógica detrás de Kage, qué es la Cota de Moore y cómo nuestra implementación resuelve el problema de las jaulas de manera óptima.
